# Локальный CA для ручной проверки RSS ЕИС

Эта папка нужна только в том случае, если Docker не доверяет TLS-цепочке
`zakupki.gov.ru`. Она не включает polling и не отправляет ничего в Telegram.

1. Получите корневой и выпускающий сертификаты НУЦ Минцифры только из
   официального канала и проверьте их отпечатки вне этого репозитория.
2. Сохраните оба PEM-сертификата локально. Поддерживаются официальные имена
   `russian_trusted_root_ca_pem.crt` и `russian_trusted_sub_ca_pem.crt` либо
   сокращённые `russian-trusted-root-ca.crt` и `russian-trusted-sub-ca.crt`.
3. Не коммитьте и не пересылайте эти файлы в чат. Git игнорирует всё в этой
   папке, кроме данного README.
4. Перезапустите dev-сервисы. Их entrypoint проверит PEM-формат и добавит оба
   сертификата в trust store только внутри каждого dev-контейнера.

Если файлов нет, Docker работает как обычно и сохраняет строгую TLS-проверку.
Не используйте `curl -k`, `verify=false` или другие обходы сертификатов.
