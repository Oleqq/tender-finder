# Telegram Stars: вывод из эксплуатации

Stars выведены из активного кода и опубликованы на VPS. Эта инструкция нужна
только для неожиданного старого события; план запуска Stars не действует.
Подтверждённый релиз — в [CURRENT-STATE](CURRENT-STATE.md).

Текущее поведение:

- в Mini App нет кнопки покупки и обещания будущей оплаты Stars;
- маршруты создания счёта, статуса оплаты, отмены и возврата удалены;
- бот не создаёт счёт по `/subscribe`, а сообщает, что оплата в Telegram
  отключена;
- `pre_checkout_query` отклоняется через Bot API с `ok=false`, в том числе
  для ранее созданной ссылки на счёт;
- ежедневная сверка Stars, платёжные алерты и повторная обработка событий
  удалены из scheduler;
- миграции и существующие таблицы сохранены для совместимости с БД.

Неожиданное `successful_payment`, `refunded_payment` или `subscription` событие
после релиза сохраняется в `telegram_updates` со статусом `ignored` и
отмечается в Laravel-логе как
`telegram.payment_update_received_after_retirement`. Обработчик не создаёт
подписку и не выдаёт доступ. В такой ситуации нужно вручную сверить запись с
Telegram и решить вопрос с получателем через поддержку. Не менять
`payments` и `entitlements` прямой правкой БД.

Историческую реализацию и прежние команды можно посмотреть в Git до этого
изменения. Текущий план возможной внешней оплаты — в
[PAYMENTS-NEXT-STAGE](PAYMENTS-NEXT-STAGE.md).
