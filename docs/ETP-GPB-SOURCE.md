# ЭТП ГПБ: официальный RSS

ЭТП ГПБ [публикует RSS актуальных процедур](https://new.etpgpb.ru/procedures/api/)
по адресу `https://etpgpb.ru/procedures.rss` и описывает его как источник для
разработчиков сервисов по закупкам. Интеграция читает только этот публичный
канал без аккаунта, cookies и API-ключа. Закрытые процедуры и отдельная секция
госзакупок `gos.etpgpb.ru` в этот канал могут не входить; полный охват площадки
не заявляется.

Источник `etp_gpb` подключён к общей очереди, импорту, персональному
сопоставлению и уведомлениям. Первый успешный снимок создаёт карточки без
исторической рассылки. При ошибке HTTP, сети или формата ответ фиксируется как
ошибка источника. Сопоставление пока использует только название процедуры:
структура описания живого RSS ещё не подтверждена.

В шаблоне окружения источник выключен. Для включения после smoke-проверки:

```dotenv
ETP_GPB_ENABLED=true
ETP_GPB_REQUEST_TIMEOUT_SECONDS=15
ETP_GPB_POLL_INTERVAL_SECONDS=3600
```

Проверить с production-сети HTTP-ответ, XML и несколько ссылок на карточки,
затем включить флаг и выполнить `php artisan tenders:dispatch-etp-gpb`.
Проверить `source_feeds`, `source_runs`, импортированные карточки и отсутствие
массовых уведомлений при первом запуске. Последующие новые карточки нужно
проверить в Telegram у двух beta-пользователей.

8 октября 2026 года прямой запрос к RSS из текущей среды завершился ответом
сетевого шлюза `502` до получения данных площадки. Поэтому формат проверен
тестовым RSS 2.0, но живой ответ и production-сеть ещё не подтверждены.
