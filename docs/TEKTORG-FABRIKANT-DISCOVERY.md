# ТЭК-Торг и Фабрикант: проверка прямых источников

> Проверено 12 октября 2026 года. Ни один из двух источников пока не включён
> в Tender Finder. Этот документ не описывает работающую интеграцию.

## ТЭК-Торг

Площадка опубликовала [инструкцию к API](https://www.tektorg.ru/storage/files/3/%D0%9E%D0%B1%D1%89%D0%B8%D0%B5/API/%D0%98%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%86%D0%B8%D1%8F%20%D0%BA%20API%20%D0%A2%D0%AD%D0%9A-%D0%A2%D0%BE%D1%80%D0%B3.pdf)
для данных о размещённых закупочных процедурах. В ней указан SOAP WSDL
`https://api.tektorg.ru/procedures/wsdl`. Публичные карточки и отдельные
секции также видны на сайте площадки.

Прямой запрос к WSDL из текущей среды вернул HTTP 403 со страницей защиты
Variti. Запрос к `www.tektorg.ru` перешёл в цикл HTTP 307 на тот же URL и
закончился HTTP 403. Поэтому контракт SOAP, формат живого ответа, доступность
из production-сети и условия использования данных ещё не проверены. Код
клиента по предполагаемой схеме ответа добавлять нельзя.

Следующий шаг: получить доступный ответ WSDL из сети сбора или разрешённый
доступ к API, проверить методы и лимиты, затем создать отдельный клиент с
выключенным по умолчанию флагом и интегрировать через существующий импорт.

## Фабрикант

У площадки есть [публичный поиск процедур](https://www.fabrikant.ru/procedure/search)
с карточками, датами, ценами и статусами. [Описание нового поиска](https://www.fabrikant.ru/news/novyy-poisk-torgovykh-protsedur-na-etp-fabrikant-udobstvo-i-effektivnost-dlya-postavshchikov/)
подтверждает, что разные секции собраны в одном интерфейсе. Отдельно есть
[реестр 44-ФЗ](https://44.fabrikant.ru/44/catalog/procedure/published).

Текущая среда не получила HTML прямого поиска: сетевой шлюз ответил 502 при
создании HTTPS-туннеля. Выделенный домен 44-ФЗ оборвал TLS-чтение. Индекс
веб-поиска показывает карточки, но не даёт проверенного HTML-контракта для
парсера, пагинации и отбора именно закупок. Доступность с production VPS
не проверена.

Следующий шаг: получить живой HTML и несколько страниц результатов из сети
сбора, отделить закупки от продаж и архивных процедур, подтвердить ссылки и
поля, затем добавить ограниченный опрос с выключенным по умолчанию флагом.

## Общие критерии включения

- Источник обращается прямо к домену площадки, без учётных данных, CAPTCHA,
  подмены TLS или обхода сетевой защиты.
- Живой ответ, пагинация, дата и ссылка проверены из сети production-сбора.
- Первый снимок не создаёт массовую рассылку, повторный опрос не создаёт
  дубликаты, ошибка источника не считается пустой выдачей.
- Карточки проходят существующие импорт, сопоставление с личными
  мониторингами, фильтры и уведомления. До smoke-проверки флаг выключен.
