# Архив: источник ЕИС RSS

Интеграция выведена из эксплуатации 26 сентября 2026 года.

Из приложения удалены URL builder и validator, RSS/XML и HTML-парсеры,
справочники, ручной поиск, enrichment, scheduler, queue job, команды CLI,
маршруты и интерфейс рабочего места ЕИС. Runtime больше не обращается к
`zakupki.gov.ru`.

Исторические тендеры, снимки запусков и связи в базе не удаляются, чтобы не
разрушать пользовательскую историю и аудит. Forward-only миграция переводит
старые ленты и мониторинги без RosTender в состояние `paused`.

Активный источник мониторинга описан в
[ROSTENDER-INTEGRATION](ROSTENDER-INTEGRATION.md).
