# **4. Пользовательские сценарии** 

# **<mark>4.1. Онбординг и пробный период</mark>** 

<mark>1. Пользователь запускает бота → /start.</mark> 

<mark>2. Бот: приветствие, краткое описание, запрос согласия на обработку ПДн и оферту (кнопки «Принять» / «Отмена»).</mark> 

<mark>3. После согласия создаётся профиль, автоматически активируется</mark> **<mark>пробный период 3 дня</mark>** <mark>со всеми функциями тарифа PRO.</mark> 

<mark>4. Мастер настройки: пользователь создаёт первый поисковый запрос (ключевые слова → фильтры → подтверждение).</mark> 

<mark>5. Бот показывает пример найденного тендера и включает рассылку.</mark> 

# **<mark>4.2. Ежедневная работа</mark>** 

- <mark>Новый тендер, подходящий под запрос, приходит уведомлением в течение ≤ 30 минут после публикации.</mark> 

- <mark>В заданное время (по умолчанию 09:00 МСК) приходит дайджест за сутки.</mark> 

- <mark>Пользователь управляет запросами командами (создание, пауза, удаление, лимиты по тарифу).</mark> 

# **<mark>4.3. Окончание пробного периода и оплата</mark>** 

<mark>1. Напоминания: за 24 часа и за 3 часа до конца trial.</mark> 

<mark>2. После окончания trial —</mark> **<mark>paywall</mark>** <mark>: запросы замораживаются (данные сохраняются), новые уведомления не приходят.</mark> 

<mark>3. /subscribe → выбор тарифа → оплата (ЮKassa / Telegram Stars) → подписка активируется мгновенно, запросы размораживаются.</mark> 

<mark>4. Автопродление: списание раз в месяц; при неудаче списания — 3 повтора (день 1, 3, 7), затем подписка переводится в статус expired.</mark> 

# **<mark>4.4. Администратор</mark>** 

- <mark>Видит воронку (регистрации → trial → оплата), управляет источниками, делает массовые рассылки (анонсы, изменения тарифов), обрабатывает обращения поддержки.</mark>

<mark>2. Новый тендер ЕИС доставляется подписчику ≤ 30 минут после публикации.</mark> 

<mark>3. Trial ровно 72 часа; paywall и напоминания работают по расписанию.</mark> 

<mark>4. Оплата ЮKassa активирует подписку мгновенно, чек 54-ФЗ доставлен.</mark> 

<mark>5. Автопродление и отмена подписки работают; данные при отмене сохраняются до конца оплаченного периода.</mark> 

<mark>6. Лимиты тарифов соблюдаются; антиспам-батчинг работает.</mark> 

<mark>7. Админка показывает пользователей, платежи, статусы парсеров.</mark> 

<mark>8. Передана документация (README, .env.example, инструкции, регламент).</mark>
