# Уведомления Telegram и переход в Mini App

Обновлено 29 октября 2026 года.

## Дайджест по выбранному времени

- Личный дайджест сообщает только о новых совпадениях личных мониторингов за
  соседние окна выбранного локального времени (например, вчера 09:00 → сегодня
  09:00); просроченные карточки исключаются. Если совпадений нет, сообщение не отправляется.
- Командный дайджест — отдельная настройка команды. Для новых команд он
  выключен. При включении отправляется владельцу только тогда, когда есть
  открытые разборы; пустая очередь не создаёт уведомление. Перед доставкой
  очередь проверяется повторно, чтобы уже закрытые разборы не дали пустое
  сообщение.
- Мгновенные совпадения и напоминания не зависят от этих двух дайджестов.

## Кнопка и целевой экран

У всех исходящих текстовых сообщений бота есть кнопка **«Открыть Tender
Finder»**. В тексте нет технического URL. Цель кнопки зависит от события:

| Событие | Экран |
| --- | --- |
| Личный дайджест | Лента «Все мои темы» |
| Новое совпадение, изменение, срок или действие | Карточка тендера |
| Командный дайджест, назначение или просрочка разбора | Лента выбранной команды |
| Задача, упоминание или согласование | Заявка по тендеру и команда, если есть |
| Окончание trial | Тарифы |
| Изменение ручного доступа | Профиль |
| Команда `/paysupport` | Поддержка |
| Команды `/start` и `/help` | Лента тендеров |

Ссылка кнопки ведёт на публичную точку `/open` с ограниченным набором
параметров. Если Telegram WebView открылся без сессии, он сначала подтверждает
подписанный `initData`, перезагружает `/open` и затем переходит на нужный
защищённый экран. Первый запуск без доступа ведёт в onboarding. Параметры не
принимают произвольный внешний URL; доступ к команде и тендеру проверяется
соответствующим экраном. Старые сообщения Telegram с уже отправленным URL
редактировать задним числом нельзя.

Stars выведены из эксплуатации. `/subscribe` не создаёт счёт,
`pre_checkout_query` отклоняется; [обработка старых событий](TELEGRAM-STARS-RUNBOOK.md).
Реальная оплата остаётся выключенной.

## Приёмка

Автотесты проверяют пустую командную очередь, доставку личного дайджеста без
URL в тексте, целевые Mini App ссылки, ограничение входных параметров и
переход без сессии. В Telegram Desktop после релиза нужно открыть по одному
сообщению каждого типа и проверить целевой экран, включая свежий WebView.

В production 19 октября после релиза вручную отправлены `/help` и
`/paysupport`: ответы пришли с кнопкой, а она открыла соответственно ленту
тендеров и экран поддержки. При этом найден и исправлен неверный URL webhook:
Bot API был настроен на `/api/telegram/webhook` (404), тогда как действующий
маршрут — `/telegram/webhook`. После `setWebhook` очередь входящих обновлений
опустела. Это не заменяет проверку следующего естественного дайджеста.
