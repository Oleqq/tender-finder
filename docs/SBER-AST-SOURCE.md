# Публичный источник Сбер АСТ

## Проверка 14 октября 2026

На VPS прямой `sber_ast` выключен, его активных лент и запусков нет. Поэтому
HTTP 500 из сообщения коллеги нельзя приписать текущему production-опросу.
Настроенный адрес `https://utp.sberbank-ast.ru/VIP/List/PurchaseList` при
повторной проверке с VPS не установил TCP-соединение за 20 секунд: `curl`
завершился по тайм-ауту с `http_code=000`, а не с HTTP 500. Главная
[официальная страница Сбер АСТ](https://psi.sberbank-ast.ru/) содержит переходы
к разным реестрам, но пока не подтверждает доступный из VPS стабильный
публичный HTML-реестр, с которым работает наш парсер.

Частичный `sber_ast_catalog` через B2B-Center включён: последний успешный
опрос 14 октября в 03:48 UTC сохранил 45 карточек. Это даёт часть закупок,
но не полноту прямого реестра. Включать прямой источник только по факту
существования сайта нельзя: сначала нужны точный рабочий URL реестра, доступ
с VPS, проверка HTML и ссылок на карточки, затем один контролируемый опрос.
Для расследования именно HTTP 500 нужны URL и метод запроса коллеги, время,
статус, заголовки и начало тела ответа без cookies, токенов и персональных
данных. После этого можно сравнить запрос с VPS и определить, отвечает ли
ошибкой сама площадка, её защита или наш клиент.

## Частичный каталог через B2B-Center

Отдельный источник `sber_ast_catalog` читает открытую
[страницу закупок Сбер АСТ](https://www.b2b-center.ru/search/etps/ao-sberbank-ast/)
на B2B-Center. Он не использует API, аккаунт или cookies Сбер АСТ.
Собираются только карточки, которые B2B-Center показывает на ограниченном
числе страниц; это не полный реестр площадки. Ссылки на исходные извещения
сохраняются отдельно. Настройка: `SBER_AST_CATALOG_ENABLED=true` и общие
`PLATFORM_CATALOG_*` параметры. Прямой `sber_ast` при этом остаётся
независимым и выключенным до проверки доступного реестра.

5 октября 2026 года каталог включён на VPS. Первый опрос пяти страниц
завершился успешно: сохранено 48 карточек, у всех есть срок, сумма и ссылка
на извещение ЕИС. Первая страница отдельно дала 10 карточек. Совпадений с
действующими пользовательскими мониторингами на момент проверки не было.

Прямой источник `sber_ast` рассчитан на общедоступные строки реестров закупок. Он
не выполняет вход на площадку, не хранит логин, пароль, cookies или электронную
подпись участника.

## Настройка

```dotenv
SBER_AST_ENABLED=true
SBER_AST_REGISTRY_URLS=https://utp.sberbank-ast.ru/VIP/List/PurchaseList
SBER_AST_REQUEST_TIMEOUT_SECONDS=15
SBER_AST_POLL_INTERVAL_SECONDS=3600
SBER_AST_USER_AGENT="TenderFinder/1.0 (+public procurement monitoring)"
```

`SBER_AST_REGISTRY_URLS` принимает разделённый запятыми список. Разрешены
только HTTPS-адреса домена `sberbank-ast.ru` и его поддоменов. Удалённые из
конфига ленты автоматически переводятся на паузу.

Scheduler раз в минуту выполняет `tenders:dispatch-sber-ast`. Команда ставит
в очередь не более одного реестра, срок опроса которого наступил. Первый
успешный снимок наполняет базу без исторического шквала уведомлений; следующие
новые карточки проходят через общие пользовательские правила.

## Ограничения первой версии

- Обрабатывается первая публичная страница каждого настроенного реестра.
- Парсер рассчитан на серверную HTML-таблицу со ссылками `PurchaseView`.
- Сбер АСТ разделён на торговые секции; каждую дополнительную секцию нужно
  проверить отдельно перед добавлением её URL в production.
- Из локального окружения площадка может быть недоступна через внешний proxy.
  Перед включением нужен пробный запуск из production-сети и проверка числа
  импортированных строк и ссылок на карточки.

## Проверка 1 октября 2026

Настроенный публичный endpoint `/VIP/List/PurchaseList` не ответил с VPS
после 20 секунд ожидания; повторная попытка ранее также завершилась тайм-аутом.
Главная `www.sberbank-ast.ru` также не дала HTTPS-ответа. Источник
остаётся выключенным на production. Нельзя показывать сетевой тайм-аут как
«нет тендеров». Для включения нужна реальная доступная публичная выдача и
проверка парсера на её HTML. Международная секция `world.sberbank-ast.ru`
публикует отдельный исторический реестр; она не является проверенной заменой
актуального реестра закупок для этого продукта.
