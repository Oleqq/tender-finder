# Страница реквизитов

Добавлена 22 октября 2026 года. Данные взяты из предоставленного оператором
файла `Реквизиты.PDF.pdf`: ИП Калиновский Роман Михайлович,
ИНН `502479440033`, ОГРНИП `326508100423744`.

- Публичный адрес: `/requisites`, вход в Telegram не требуется.
- Ссылка в приложении: **Профиль → Реквизиты**, рядом с офертой и политикой.
- На странице: регистрационные данные, юридический адрес, все банковские
  реквизиты из PDF, кнопки копирования и скачивания исходного документа.
- Источник текстовых данных: `config/company.php`. Номера счетов и
  идентификаторы хранятся строками, включая начальный ноль БИК.
- Исходный PDF: `public/documents/requisites.pdf`, доступен для скачивания
  по `/documents/requisites.pdf`.
- Интерфейс использует текущую светлую и тёмную темы; на телефоне строки
  располагаются вертикально, длинные значения переносятся.

При изменении реквизитов обновляйте одновременно конфигурацию и PDF.
Страница не зависит от флага публикации оферты и политики и не меняет его.
Добавление реквизитов не включает приём платежей.

## Проверка

- TypeScript и production-сборка Vite, ESLint, форматирование изменённых
  PHP/TSX-файлов прошли.
- В Chromium проверены обе темы на ширинах 320, 360, 390, 768 и 1280 px:
  горизонтального переполнения и обрезанных значений нет.
- Проверены гостевой вход, переход **Профиль → Реквизиты → Назад**,
  копирование всех десяти полей и сообщение при отказе буфера обмена.
- Все десять текстовых значений сверены с исходным PDF; SHA-256
  скачанного через HTTP документа совпадает с исходным файлом.
- Необработанных JavaScript-исключений при браузерной проверке нет.

## Выпуск

Публикация выполняется по [порядку VPS-релиза](VPS-DEPLOYMENT.md).
После обновления проверьте публичные `/requisites` и
`/documents/requisites.pdf`, совпадение SHA-256 PDF с исходником,
загрузку собранного JS/CSS страницы и переход из профиля.
