# Источник Workspace.ru

Источник `workspace_ru` получает digital-тендеры из официального публичного
RSS `https://workspace.ru/tenders/rss/`. Авторизация, cookies пользователя и
PRO-аккаунт для чтения фида не используются.

## Настройка

```dotenv
WORKSPACE_RU_ENABLED=true
WORKSPACE_RU_FEED_URL=https://workspace.ru/tenders/rss/
WORKSPACE_RU_REQUEST_TIMEOUT_SECONDS=15
WORKSPACE_RU_POLL_INTERVAL_SECONDS=3600
WORKSPACE_RU_USER_AGENT="TenderFinder/1.0 (+public tender RSS monitoring)"
```

Принимаются только HTTPS-адреса `workspace.ru` и его поддоменов. При изменении
URL прежняя лента автоматически переводится на паузу.

Scheduler раз в минуту выполняет `tenders:dispatch-workspace-ru`, а фактический
опрос происходит с заданным интервалом через очередь. Первый снимок импортирует
имеющиеся карточки без уведомлений. Новые карточки последующих снимков проходят
через общие правила мониторингов.

Из RSS сохраняются заголовок, ссылка, описание проекта, требуемая услуга,
организационный тип заказчика, дата публикации, крайний срок и бюджет. Для
диапазона бюджета в основном поле используется верхняя граница, обе границы
остаются в metadata.

Рубрика «Требуемая услуга» показывается в описании, но исключена из текста
для сопоставления. Иначе общая рубрика «разработка сайтов» давала совпадения
заданиям про рекламу и криптоплатежи. Быстрый поиск дополнительно проверяет
связную фразу и название.

27 сентября 2026 года парсер проверен на реальном фиде: источник вернул 50
карточек, первая запись корректно разобрана вместе с бюджетом и сроком.

1 октября реальный HTTP 200 и разбор 50 карточек повторно подтверждены с VPS.
Общий поиск может работать без RosTender: RSS обновляется независимо, а
каждый мониторинг получает собственные совпадения по словам и фильтрам.
Это текущие записи RSS, не полный архив и не удалённый строковый поиск.
HTML вместо RSS, отсутствие channel и непустой фид без валидных карточек
считаются ошибкой; корректный пустой RSS остаётся успешным пустым ответом.
Просроченные карточки не добавляются в новые совпадения.

Production-включение 1 октября импортировало 50 карточек; первые 2 личных
совпадения действующего мониторинга появились без исторической рассылки.
