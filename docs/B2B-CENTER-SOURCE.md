# Источник B2B-Center

Источник `b2b_center` читает общедоступную выдачу B2B-Center через тот же
JSON-маршрут, который использует сайт: `/site/api/v1/market-search/`.
Авторизация, cookies, электронная подпись и платный API личного кабинета не
используются. Из ответа импортируются номер процедуры, название, организатор,
даты публикации и окончания, регион и цена при наличии.

```dotenv
B2B_CENTER_ENABLED=true
B2B_CENTER_CATALOG_URL=https://www.b2b-center.ru/market/
B2B_CENTER_REQUEST_TIMEOUT_SECONDS=15
B2B_CENTER_POLL_INTERVAL_SECONDS=3600
B2B_CENTER_PAGES_PER_POLL=5
B2B_CENTER_USER_AGENT="TenderFinder/1.0 (+public tender catalog monitoring)"
```

Сохранённая идентичность ленты использует только HTTPS URL официального домена
с точным путём `/market/` и либо без параметров, либо с точной парой
`f_keyword`/`searching=1`. При опросе фраза передаётся в `query`, а результат
ограничивается вкладкой актуальных закупок и максимумом страниц из настройки.
Если гостевой маршрут повторяет предыдущую страницу, сбор останавливается.
Источник выключен в шаблонах окружения: перед включением в production нужно
проверить доступность выдачи. Изменение JSON-структуры считается ошибкой
опроса и не перезаписывает успешный снимок пустым результатом. Маршрут сайта
не является документированным публичным API, поэтому его формат может
измениться.

## Поиск по ключевой фразе

Для активного мониторинга создаётся общая лента его фразы;
одинаковые фразы используют один опрос и интервал, но отдельные личные
совпадения. Пауза последнего мониторинга останавливает такую ленту.
Дополнительные параметры, фрагменты и другие домены клиент отклоняет.

Проверена реальная выдача «разработка сайта»: одна актуальная карточка
№4616411. Пустой ответ принимается только при нулевом счётчике актуальных
закупок; HTTP-ошибка или изменённая структура считаются ошибкой опроса.

Охват ограничен заданным числом страниц. Фраза передаётся в открытую выдачу,
затем применяются локальные all/any/exact и остальные фильтры.
Локальный режим any не расширяет уже ограниченную выдачу площадки. Длинные
совокупности ключевых слов свыше 255 символов используют общий каталог.
Полная эквивалентность сложных условий остаётся отдельной задачей.
Быстрый поиск дополнительно проверяет связную фразу и название, не считает
общую категорию текстом задания и связывает результат только с мониторингом,
чья фразовая лента получила карточку. При первом production-опросе через
прежнюю HTML-таблицу импортирована 21 карточка.

## Уточнение структуры заголовка

В живой выдаче 1 октября некоторые `search-results-title-desc` содержали
вложенный `div` с номером, организатором и категорией. Например, аренда ДГУ
получала текст рубрики «Электросети (строительство и проектирование)» внутри
импортированного названия и ложно попадала в тему «строительство». Парсер
берёт текст заголовка без вложенных блоков, но сохраняет категорию отдельно
в metadata. При следующем импорте изменённые заголовки перепроверяют уже
созданные совпадения. Локально 20 B2B-совпадений по теме сократились до семи.

Прежняя серверная HTML-таблица исчезла после перехода сайта на новую выдачу.
Сбор переключён на открытый JSON-маршрут сайта. Проверка без авторизации
показала, что `page=2` и увеличенный `page_size` возвращают те же первые 20
карточек общего каталога, хотя счётчик сайта показывает тысячи. Фактический
охват в этом режиме остаётся первой страницей; число на сайте не означает,
что все эти тендеры попали в TenderFinder.
