# Источник B2B-Center

Источник `b2b_center` читает только общедоступную серверную таблицу
`https://www.b2b-center.ru/market/`. Авторизация, cookies, электронная подпись
и платный API личного кабинета не используются. Из списка импортируются номер
процедуры, название, категория, организатор, даты публикации и окончания.

```dotenv
B2B_CENTER_ENABLED=true
B2B_CENTER_CATALOG_URL=https://www.b2b-center.ru/market/
B2B_CENTER_REQUEST_TIMEOUT_SECONDS=15
B2B_CENTER_POLL_INTERVAL_SECONDS=3600
B2B_CENTER_USER_AGENT="TenderFinder/1.0 (+public tender catalog monitoring)"
```

Разрешён только HTTPS URL официального домена с точным путём `/market/` и либо без
параметров, либо с точной парой `f_keyword`/`searching=1`. Источник выключен в шаблонах окружения: перед включением
в production нужно повторно проверить доступность страницы и актуальные
условия площадки. Изменение структуры таблицы считается ошибкой опроса и не
перезаписывает успешный снимок пустым результатом.

## Поиск по ключевой фразе — 1 октября 2026

Публичная форма каталога действительно использует GET `f_keyword` и
`searching=1`. Для активного мониторинга создаётся общая лента его фразы;
одинаковые фразы используют один опрос и интервал, но отдельные личные
совпадения. Пауза последнего мониторинга останавливает такую ленту.
Дополнительные параметры, фрагменты и другие домены клиент отклоняет.

Проверена реальная выдача «разработка сайта»: карточка №4616411.
Настоящий пустой ответ распознаётся по `search-results empty_results` и
сообщению об отсутствии актуальных процедур; пустая таблица, HTTP 503 или
изменённая вёрстка считаются ошибкой, а не успешным нулевым результатом.

Охват пока ограничен одной страницей. Фраза передаётся согласно публичной
форме площадки, затем применяются локальные all/any/exact и остальные фильтры.
Локальный режим any не расширяет уже ограниченную выдачу площадки. Длинные
совокупности ключевых слов свыше 255 символов используют общий каталог.
Пагинация и полная эквивалентность сложных условий — отдельный следующий этап.
Production-включение и проверки отмечаются в [MULTISOURCE-SEARCH-QA](MULTISOURCE-SEARCH-QA.md).
