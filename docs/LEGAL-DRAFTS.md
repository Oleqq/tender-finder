# Tender Finder: черновики юридических документов для закрытой beta

> **Статус: не публиковать и не использовать для принятия условий.** Это общий
> рабочий черновик для российского ИП. Он не заменяет юридическую консультацию,
> оферту или политику конфиденциальности. До публикации заполните реквизиты,
> выберите провайдеров в РФ и получите проверку юриста.

## Черновик оферты: что должен подтвердить юрист

1. Полные реквизиты ИП, адрес для обращений и контактный канал.
2. Что Tender Finder в первой закрытой beta даёт доступ к поиску, максимум трём
   мониторингам и уведомлениям; один trial длится 72 часа.
3. Что Telegram Stars, цены, автоматическое продление и возвраты в beta не
   применяются.
4. Порядок изменения условий, прекращения beta, ограничений ответственности и
   применимое право.
5. Что сервис не обещает выигрыш тендера, полноту RSS-источника или отсутствие
   задержек ЕИС.

## Черновик политики конфиденциальности: фактическая карта данных

| Данные | Зачем нужны | Чего не хранит код |
|---|---|---|
| Проверенный Telegram ID и минимальные display fields | создать сессию, показать профиль, отправить сообщение | raw `initData`, bot token, cookies, полный webhook payload |
| События согласия: документ, версия, время, HMAC-хеш IP | доказать принятие или отзыв документа без записи IP текстом | IP в открытом виде |
| Фильтры мониторинга и результаты matching | искать и объяснять подходящие тендеры | содержимое личных сообщений, документы ТЗ, LLM-prompts |
| Технический журнал доставки | не послать дубли и увидеть безопасный статус | платёжные данные до отдельного этапа Stars |

Перед публикацией юрист должен отдельно определить: цели и правовые основания
обработки, сроки хранения, порядок удаления и обращения пользователей,
контакты ИП, состав обработчиков и условия передачи данных через Telegram.
VPS, PostgreSQL и Redis для первой beta должны размещаться в РФ.

Роскомнадзор разъясняет, что владелец сайта, обрабатывающий персональные
данные, может быть оператором персональных данных; обязанности конкретного ИП
нужно проверить по актуальным обстоятельствам с юристом. См.
[разъяснение Роскомнадзора](https://82.rkn.gov.ru/directions/pers/p15375/).

## Порядок безопасной публикации

1. Юрист заменяет этот черновик на финальные тексты и подтверждает реквизиты.
2. Разработчик обновляет copy в `LegalDocument.tsx`, снимает маркировку
   «черновик» и проводит обычные проверки.
3. Оператор публикует `/offer` и `/privacy` на Vercel, задаёт реальные URL и
   версии в secret store VPS и только затем устанавливает
   `LEGAL_DOCUMENTS_PUBLISHED=true`.
4. На тестовом Telegram-аккаунте проверяются ссылки, сохранение согласий и
   запуск одного trial. Пока хотя бы один пункт не выполнен, trial остаётся
   заблокированным.
