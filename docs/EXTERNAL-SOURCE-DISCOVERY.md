# Проверка новых источников: Росэлторг и РТС-Тендер

> История прямых проверок 1–7 октября 2026 года. Актуальный обходной источник
> для обеих площадок описан в конце документа.

## Результат

В публично найденных материалах Росэлторга доступна открытая поисковая витрина
закупок, однако опубликованное API относится к отдельному сервису электронного
документооборота и тарифному доступу, а не к выгрузке реестра закупок. Для
РТС-Тендер в публично доступной документации не найден подтверждённый API или
специальный RSS/экспорт для такого мониторинга. Ни одна из этих находок не
даёт TenderFinder права на автоматический сбор или распространение карточек.

Поэтому на дату проверки 1 октября **не добавлены** HTTP-клиенты, HTML-парсеры, polling,
переменные окружения или production-флаги для этих площадок. Не используется
авторизация, чужие учётные записи, cookies, CAPTCHA или обход сетевых
ограничений.

## Что подтверждено первичными материалами

- На [открытой витрине Росэлторга](https://www.roseltorg.ru/torgi) есть поиск
  закупок и публичные карточки процедур.
- [Документация Росэлторг.ЭДО](https://www.roseltorg.ru/_flysystem/webdav/2022/12/29/RP_edo_v18.pdf)
  описывает API для создания документов в отдельном ЭДО-сервисе на тарифе
  «Корпоративный +»; это не основание использовать его для тендерной ленты.
- Открытая часть площадки и закрытые разделы различаются в
  [регламенте Росэлторга](https://www.roseltorg.ru/_flysystem/webdav/2024/01/17/rp_fkr_15012024.pdf).

Первоначально проект требовал письменное подтверждение оператора до кода.
Позднее 1 октября владелец изменил это условие; актуальное решение ниже.

## Повторная проверка 1 октября

- [Росэлторг сообщает о сохранённом поиске](https://www.roseltorg.ru/knowledge_db/systems/notes/na-roseltorg-poyavilas-vozmozhnost-sokhranyat-parametry-poiska)
  в открытой части сайта. Это пользовательская функция сайта; сообщение не
  описывает разрешённый для TenderFinder API или экспорт закупок.
- [РТС-Академия пишет](https://academy.rts-tender.ru/supplier/article/goszakupki%20s%20nulya_instrukciya_dlya_novichkov),
  что человек может искать закупки на РТС-Тендер без регистрации. В статье
  нет условий автоматического доступа, квот или разрешения показывать
  полученные карточки пользователям другого сервиса.
- До релиза 1 октября в production была активна одна лента `rostender`.
  После коммита `d930ec0` работают также Workspace.ru и B2B-Center. Сбер АСТ
  остаётся выключенным после сетевых тайм-аутов. Это не означает готовность
  Росэлторга или РТС-Тендер.

Общий контур проекта уже готов к подключению разрешённого источника:
`source_feeds` и `source_feed_items`, импорт с дедупликацией, очередь,
планировщик, сопоставление с личными мониторингами, уведомления и фильтры
личной/командной ленты. После получения контракта не требуется проектировать
вторую систему хранения или отдельный пользовательский поиск.

## Решение владельца 1 октября и текущий технический блокер

Владелец явно отменил прежнее требование ждать письменный ответ до начала
разработки по открытым страницам. Переписка больше не является обязательным
следующим действием. Это изменение процесса проекта; оно не утверждает
каких-либо отсутствующих условий площадок.

Обычные HTTPS-запросы с проверкой сертификата из VPS дали:

| Источник | Ответ | Результат разбора |
|---|---|---|
| Росэлторг, `/procedures/search` | timeout 15 с | ответа для парсера нет |
| РТС-Тендер, главная | HTTP 503, страница Anti-DDoS-проверки браузера | закупки не получены |
| Сбер АСТ, настроенный PurchaseList | timeout 15 с | источник не включаем |
| Workspace.ru, `/tenders/rss/` | HTTP 200 | 50 карточек, 16 открытых на момент проверки |
| B2B-Center, `/market/` | HTTP 200 | 20 карточек |
| B2B-Center, публичная форма с «разработка сайта» | HTTP 200 | 1 карточка №4616411, срок 9 октября |

Дополнительный запрос к официальному `/torgi` Росэлторга также
завершился тайм-аутом TCP-соединения до начала TLS. Это не доказательство
постоянной недоступности всей площадки; нужна доступная точка публичного
поиска и повторный smoke с VPS. Прямые клиенты площадок пока не добавлены:
формат ответа не подтверждён.

B2B-поиск использует реально наблюдённые поля `f_keyword` и `searching=1`.
Подтверждён и пустой HTTP 200 ответ с блоком `search-results empty_results`.
Никакие закрытые фильтры, cookies или аккаунты не используются. Обход CAPTCHA,
proxy rotation, TLS bypass и скрейпинг закрытых страниц остаются вне задачи.

При получении рабочего публичного адреса проверить содержимое и границы
доступа, добавить fixtures, allowlist, тесты и только затем включать источник.
Общий пользовательский поиск развивается независимо; его статус — в
[CURRENT-STATE](CURRENT-STATE.md).

## Проверка сетевого пути 2 октября

Пользователь сообщил, что страницы площадок открываются на его компьютере
после отключения VPN. Это важная проверка локального маршрута, но опрос
источников Tender Finder выполняет сервер, а не браузер пользователя.
Повторный запрос с хоста VPS и из контейнера `web` дал тайм-аут для
`https://www.roseltorg.ru/torgi` и HTTP 503 для
`https://www.rts-tender.ru/`. Поэтому отключение VPN на компьютере
пользователя само по себе не восстановит фоновый сбор в текущем production.

Повторная диагностика 2 октября уточнила этапы отказа. Адреса обоих доменов
совпали у системного DNS и трёх публичных резолверов. С VPS TCP-подключение
к Росэлторгу (`185.79.118.12`) не устанавливается ни на 80, ни на 443 порту;
захват трафика подтвердил выходящие SYN-пакеты и отсутствие ответа на них.
Это сужает причину до сетевого пути после VPS или фильтрации на стороне
назначения, но не показывает, где именно теряются пакеты. У РТС-Тендер
(`185.179.85.62`) TCP и TLS проходят быстро, сертификат валиден, а ответ
HTTP 503 содержит текст «Anti-DDoS защита. Проверяем ваш браузер».
Такие же результаты получены из контейнера `web`. Контрольные запросы к
B2B-Center и `rosatom.rts-tender.ru` с того же VPS вернули HTTP 200.
Следующий шаг для прямого доступа: передать хостингу время, адрес назначения
и результаты TCP/MTR-проверки Росэлторга, а у РТС-Тендер запросить
разрешённый машинный доступ или исключение для серверного IP. Эти обращения
не нужны для уже работающего опроса открытого каталога B2B-Center.

Отдельная публичная секция `https://www.rosatom.rts-tender.ru/market/`
ответила HTTP 200 и показала 20 карточек. Она покрывает секцию «Росатом»;
её нельзя считать полной выдачей РТС-Тендер. Для прямой интеграции нужны
подтверждённый адрес открытого поиска и доступ к нему из сети, где будет
работать сборщик. Неудачный ответ текущего VPS не означает,
что площадка недоступна из любой сети.

## Повторная проверка с VPS 7 октября

Для `www.roseltorg.ru` и `utp.sberbank-ast.ru` системный DNS вернул IPv4,
но TCP-соединение с портом 443 не установилось за пять секунд, а HTTPS-запрос
завершился тайм-аутом до TLS. У `www.rts-tender.ru` TCP и проверяемый TLS
завершились быстро, после чего сервер вернул HTTP 503. Таким образом, текущая
ошибка Росэлторга и прямого Сбер АСТ остаётся на сетевом пути до TLS, а
РТС-Тендер отвечает на уровне HTTP. Эти измерения относятся к текущему VPS
и не доказывают постоянную недоступность площадок. Частичные каталоги на
B2B-Center опрашиваются независимо.

## Доступный путь через B2B-Center, 2 октября

Публичный [поиск B2B-Center](https://www.b2b-center.ru/search/) группы B2B-РТС
показывает закупки других площадок с названием оператора, суммой, датами,
заказчиком и ссылкой на извещение. Его отдельные страницы
[АО «ЕЭТП»](https://www.b2b-center.ru/search/etps/ao-eetp/) и
[РТС-тендер](https://www.b2b-center.ru/search/etps/rts-tender/) ответили
локально и с production VPS по HTTPS (по 10 карточек, HTTP 200).
На каждой странице видны 10 карточек; параметр
`Page=2` возвращает следующую страницу. Заголовок и ссылки карточек
проверены перед импортом. Прямые сайты площадок по-прежнему не дают серверу
полезный ответ.

Для этих двух страниц добавлен ограниченный опрос (до 5 страниц на площадку
каждые 30 минут по умолчанию) через общий импорт, сопоставление и уведомления.
В интерфейсе источник явно помечен оператором, карточка открывается на
B2B-Center, ссылка на исходное извещение хранится отдельно. Это не API или
полная синхронизация Росэлторга/РТС: записи за пределами просмотренных
страниц, закрытые процедуры и возможные задержки агрегатора остаются вне
охвата. Доступность и объём на VPS следует проверять после каждого релиза.
